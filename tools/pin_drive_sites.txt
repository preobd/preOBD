# pin_drive_sites.txt -- every place in src/ that configures, drives or reads
# a pin directly (or through a listed wrapper), and why it may. Checked by tools/check_pins.py (pre-commit).
# Measured 2026-11-14 against main @ adf15c4. A pinMode key carries its mode
# too, so a reader that becomes a driver changes its key. Rules: ARCHITECTURE.md §12.
#
# THIS IS A RATCHET, NOT A WALL. A site not listed here fails the commit,
# and so does a line whose site is gone. Before adding a line, check that the
# code drives only a pin it claimed first through pin_owner.h and still
# holds (§12.5): a refused claimant must never touch its pin.
#
# Format: <path>  <function>  <call>  <first-arg>   # <TAG>: <why>, citing #N or §N
# Tags:
#   CLAIMED        -- the pin is claimed first and the drive is skipped when
#                     the claim is refused. The comment says where; only
#                     review checks it.
#   RATCHET TARGET -- drives without a held claim. Cites the issue that
#                     removes it; the line goes when that issue is fixed.
#   UNHELD         -- deliberately touches a pin nobody holds (a diagnostic
#                     sweep); the comment says why it is safe.
#   MACRO          -- a helper macro's body; the macro is in PIN_CALLS, so its
#                     call sites are listed too.
# The tag is the first word(s) of the comment. Two identical calls in one
# function are two identical lines. Regenerate keys with check_pins.py --list.
